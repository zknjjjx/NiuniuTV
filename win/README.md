# 妞妞影视 Windows 版

由 CineNest 网页版（zknjjjx/CineNest，快照 d5c8349）改成的独立 Windows 客户端：后端与页面一起打包进单个 exe，只在本机 127.0.0.1:38990 运行，不需要 N1 或 NAS。

- 下载：Release v2-latest 里的 NiuniuWin-<版本>.exe，双击即用，免安装
- 系统：Windows 10/11（需要 WebView2，Win11 自带，Win10 一般已有）
- 数据：%APPDATA%\NiuniuWin（设置、片源缓存、日志 niuniu.log）
- 首次运行自动填好妞妞默认片源接口
- cinenest/ 是 CineNest 的副本，品牌改为妞妞影视；CineNest 仓库本身不动
